## Why clean is unreachable, not merely unreached

The verdict stayed `INCOMPLETE` across all three Gate 2 runs, with obligations
lacking discriminating test evidence going 11 → 9 → 8. Each step came from a real
fix. The remaining eight do not yield to more of the same:

- **Three restate one documented limit.** The network block is at the Python
  socket layer, not the operating system's, so a C extension opening a socket
  directly is not caught. There is no portable way to get an operating-system
  network namespace on macOS without privileges. That defect stays enumerated and
  unkilled, so `network-access-blocked-for-tests` cannot be strongly supported,
  and the gate requires every obligation strongly supported.
- **Three are factually wrong about the code**, checked line by line — the
  `_ALLOWED_FAMILIES` reading is inverted, `PYTHONNOUSERSITE=1` is read as
  disabling the wrong thing, and `PYTHONPATH` is said not to point at the plugin
  directory when it is set to exactly that.
- **Two name paths the public API cannot reach** — a per-test budget of zero,
  which `SandboxConfig` rejects at validation, and an empty request, which is
  deliberate.

## What was built

`src/acceptance/execution/`, standalone. Nothing referenced
`Component.COVERAGE_RUNNER` or `Component.MUTATION_RUNNER` before, and nothing
does now — elevating a tier belongs to #42 (M8.1, the feasibility probe) and #44
(M8.3, the coverage-confirmed tier).

- `outcome.py` — five per-test outcomes with a reason required on every one that
  is not a completed run.
- `netblock.py` — a standalone stdlib-only pytest plugin, copied into a temp
  directory and loaded with `-p` by the project's own interpreter. Installs the
  network block before the first test import, arms the per-test alarm, flushes
  each outcome as it finishes.
- `sandbox.py` — one pytest subprocess over the named node ids, in a new session,
  with an allowlisted environment, killing the process group on the whole-run
  budget. Returns on every failure path rather than raising.

Ten injected defects, all killed. Four tests had to be rewritten because
injection showed they proved nothing; that history is in the judgement files.
