## Two things this gate settled that later work depends on

1. **`test_demand` obligations are excluded from defect enumeration.** DR-313
   decision 2. It resolves a conflict in DR-312: the enumerator never sees the
   tests (the #252 mitigation), but a `test_demand` obligation is about a test.
   **Consequence for #314 and #316: an absent defect set must be distinct from an
   empty one.** #313's own mandate produced six `test_demand` obligations, so
   this is not a corner case.
2. **A completion expectation should say what a test must assert, not when a
   test must fail.** Derivation inverts "a test fails when X" unreliably — 5 of 7
   in run 3, the same 5 of 7 in run 4, on two different wordings. Recorded
   against #262, the issue for a paraphrase that does not preserve entailment.
