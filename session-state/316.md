## Numbers worth not re-deriving

- The pair stage cost **$3.51 of a $4.25 review** at #314's Gate 2 — 332 calls,
  546,143 output tokens. Pricing: prompt $0.75/M, output $4.50/M.
- The union response shape saves **$0.44 of that $2.46**, and changing the
  response schema re-judges every recorded verdict once, about **$3.50** one-off.
- **Defect-id aliasing does not work.** Per-batch short ids cut output 25% and
  lose a third of the labelled kills, returning zero on four of thirteen cases.
  Do not retry it; a shorter but still *meaningful* id is the untested variant.
- **Three seeds are not enough** to separate response shapes differing by one or
  two labelled edges. One arm reversed between three draws and nine.
- Defect deduplication is **#321**, filed, blocked on #304.

## A CLAUDE.md rule that post-dates #314's task files

Task files are now written at ticket grade: say each requirement once, do not
pre-enumerate the obligation set in a completion list, and never pair "do X" with

produced the near-duplicate obligations collapsed by hand across three decompose
runs. Write #316's task file the new way.
