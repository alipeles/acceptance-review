## The plan Gate 1 was presented with

Four blocks, in this order. Nothing is started.

1. A run-scoped assembler that builds each request from **named content blocks**
   rather than a hand-ordered string, and orders them by a declared rank.
2. Move each stage's instructions out of the `system` message into a ranked
   block, leaving a single system message identical across every request of a
   run. Without this every request diverges at message 0 and no cross-stage
   prefix exists. **This is the load-bearing decision** — queued in
   `docs/DEFERRED.md` for approval.
3. A provider-side marker behind the client (`llm.py`), since Anthropic needs
   explicit `cache_control` breakpoints and OpenAI needs none. `cache_control`
   appears nowhere in `src/` or `tests/` today.
4. The DR #265's Acceptance requires, written as the work goes, not after.
