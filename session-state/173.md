## Why this one is first

It makes a gate **unreachable by iteration rather than merely unreached**. When
the tool prescribes a test that already exists, no honest change satisfies the
finding — and writing a second test to coax the mapper is the forbidden kind of
edit. #293 had to ship with Gate 2 deliberately not clean because of it.

It also comes before #150 (mapping stability, reopened) for a measurement reason:
while #173 stands, a gate run against mapping work cannot distinguish a real
improvement from a lucky sample.
