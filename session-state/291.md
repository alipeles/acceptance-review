## Do not rediscover

- **"No open questions" is not evidence of anything.** A requirement's
  disposition is exactly one of `yielded` / `open_question` / `no_obligation`, so
  a requirement that produces an obligation cannot also raise a question. The
  last dogfood run to print an `Open questions:` section is
  `dogfood-logs/202-gate1-run{1,2}/` — nothing in ~30 issues since. Gate 1 step 3
  ("triage every open question") is currently vacuous. Found by the #265 session;
  `dogfood-logs/291-gate1-run1/judgement.md` carries the correction.
- **Local `ruff` can pass a tree CI rejects, for reasons other than the pin.** A
  script importing a module that exists only on an unmerged branch makes ruff
  classify it third-party and raise I001 — but only on a checkout without that
  branch. Lint against a checkout that does *not* have your branch. Cost two red
  commits on main on 2026-08-20.
- **Injecting an import from `acceptance.requirement` into `acceptance.carry` is
  a circular import, not a clean test failure.** `ledger.py` imports `carry_key`
  from it. Use `acceptance.evidence` to inject that defect instead.
- **The formatter hook strips a newly added import before its first use exists.**
  Append the code that uses it first, then add the import.
- **`git switch -C <name> origin/main` fails in this worktree** and leaves the
  switch partway done. Use `git branch --no-track <name> origin/main` then
  `git switch <name>`.
- **`session-state/*.md` is committed on `main`, not on a branch.** Switching
  branches deletes it from the working tree. Restore with
  `git show origin/main:session-state/<n>.md > session-state/<n>.md`.
