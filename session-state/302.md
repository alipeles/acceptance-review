## Scope, narrowed — DECIDED 2026-08-21 by the human

**#302 as filed names three fields. Only `test_id` on the mapping stage is being
changed.** `requirement_id` (decompose) and `pair_id` (linking) keep their enums.

The reason is measured, not cautious. The provider caches a prefix only from
**1,024 tokens** up:

| stage | calls | hit % | within-run shared prefix | above the floor? |
|---|---:|---:|---:|---|
| **mapping** | 464 | 0.7 | **1,729** | **yes** |
| decompose | 43 | 8.9 | 694 | no |
| linking (two clusters) | 77 + 62 | 0.0 | 583, 509 | no |

Decompose and linking are below the floor, so a stable schema **cannot** produce a
hit there whatever it does — linking already measures 0.0% and would still measure
0.0%. Removing those two enums cost a full corpus re-record and the
`_APPROVED_TRANSCRIPTS` sign-off for nothing.

Ten re-records per arm put the prompt-corpus capability tests at **2/10 failing
with the decompose enum removed against 0/10 with it kept** — Fisher exact
p = 0.474, which neither shows a regression nor excludes one. An unresolved risk
for zero benefit is not a trade.

**The narrowing is what removed the re-record entirely**: the seven committed
fixtures are decompose ×3, disposition ×3 and linking ×1, and **none is mapping**.

## The measurement, so it is not re-derived

`docs/DR-302-per-batch-id-enum.md` carries all of it. Two facts decided the design:

- **The response schema is billed as prompt tokens.** Two live calls, identical
  messages, schema differing by 11,822 bytes → **+2,927 prompt tokens**.
- **`inline_schema_refs` must inline every `$ref`** (#158), so the fixed-slot
  mechanism #302 proposes would inline N copies of the item model: mapping's
  schema goes 1,233 → **13,055 bytes** at N=12. That is +57% on a 5,145-token mean
  request to make 34% of it eligible. **The slot mechanism cannot win**, and the
  DR records it as rejected.

Expected effect on mapping: 5,145 → 4,924 prompt tokens per call, cached share
0.7% → 32.1% predicted, $1.78 → $1.22 over the 464 recorded calls. **The 32.1% is
a prediction and still needs a recorded run under #285's accounting to confirm.**
